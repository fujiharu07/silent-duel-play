# SILENT DUEL（静寂の決闘）

目が見えない 2 人が、音だけを頼りにリボルバー 6 発で撃ち合う、1 対 1 の FPS のブラウザ版。

**遊ぶ: <https://fujiharu07.github.io/silent-duel-play/>**

- PC のブラウザで、キーボードとマウスで遊ぶ。ヘッドホン推奨。
- このリポジトリには、ビルドしたもの（Unity の Web ビルド）だけを置いている。ソースは置いていない。
